# 🥭 찐망고 폴더메이커 (MangoWork)

누끼 작업한 이미지를 **품번별 / 사이즈별 폴더로 자동 정리**해주는 윈도우용 실행 파일입니다.

## 결과 폴더 구조

두 버전 모두 아래처럼 정리됩니다.

```
result/
└─ AFA4QPA5J_BK/              ← 품번 폴더
   ├─ 1440-1890/              ← 사이즈 폴더
   │  ├─ AFA4QPA5J_BK_01.jpg
   │  └─ AFA4QPA5J_BK_02.jpg
   ├─ 1732-2000/
   │  └─ ...
   ├─ AFA4QPA5J_BK_tag1.jpg   ← tag 이미지는 품번 폴더 바로 아래
   └─ AFA4QPA5J_BK_tag2.jpg
```

## 파일 이름 규칙

- 품번은 파일명의 **앞 두 덩어리**입니다 → `AFA4QPA5J_BK_07.jpg`의 품번은 `AFA4QPA5J_BK`
- tag 이미지는 이름에 `tag`를 넣어주세요 → `AFA4QPA5J_BK_tag1.jpg`, `AFA4QPA5J_BK_tag2.jpg`
- tag 이미지가 없으면 생략해도 됩니다
- 지원 형식: `.jpg` `.jpeg` `.png` `.gif`

## 버전별 차이

| | v1 | v2 |
|---|---|---|
| origin에 넣는 것 | 원본 이미지 전부 (한 폴더에) | **사이즈별로 이미 나눠진 폴더** + tag 이미지 |
| 사이즈 폴더 | 실행할 때 직접 입력 | origin 안의 폴더 이름 그대로 사용 |
| 언제 쓰나 | 같은 이미지를 여러 사이즈 폴더에 복사할 때 | 사이즈별 작업이 끝난 걸 품번별로 모을 때 |

## 사용법

### v1 — `makerv1/`

1. `origin` 폴더에 원본 이미지를 모두 넣습니다.
2. `찐망고_폴더메이커v1.exe`를 더블클릭합니다.
3. 만들 사이즈 폴더 이름을 쉼표로 구분해 입력합니다.
   예) APC → `1440-1890, 1732-2000`
4. `result` 폴더에 품번 폴더와 사이즈 폴더가 생성됩니다.

### v2 — `makerv2/`

1. `origin` 폴더에 사이즈별로 정리된 폴더(예: `2000-2000/`)와 tag 이미지를 넣습니다.
2. `찐망고_폴더메이커v2.exe`를 더블클릭합니다.
3. `result` 폴더에 품번 폴더와 사이즈 폴더가 생성됩니다.

> 원본은 그대로 두고 **복사**만 하니까 안심하고 쓰세요.

## 파일 구성

```
makerv1/
├─ 찐망고_폴더메이커v1.exe
├─ mango_v1.py     ← 소스 코드
└─ config.txt      ← 사용 안내
makerv2/
├─ 찐망고_폴더메이커v2.exe
├─ mango_v2.py
└─ config.txt
```

## exe 다시 만들기 (코드 수정 시)

윈도우에서 Python 설치 후:

```
pip install pyinstaller
pyinstaller --onefile --name 찐망고_폴더메이커v1 mango_v1.py
```

`dist/` 폴더에 exe가 생깁니다. 기존 exe를 지키려면 `--name`을 다르게 해서 테스트해보세요.
